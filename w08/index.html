燈具圖面規劃：先決定怎麼說，再開始畫
Lighting drawing plan: decide how to communicate before drawing

這不是把每個物件都硬塞進三視圖，也不是把所有內容畫成同一比例。今天要先建立圖面計畫，再用適合的視圖、比例與標註，把燈具資料整理成能被別人重建、量測與檢查的圖說。

今天的核心問題 / Core question

同一張圖面裡，哪些資訊要用三視圖精確表達？哪些要用爆炸圖說明關係？哪些細節必須放大？

Which information needs orthographic views, which needs an exploded view, and which details must be enlarged?

本週最低成果 / Minimum outcome

圖面計畫完成，並建立整體淨尺寸、三件關係，以及至少一個零件或細部的可檢查圖面。

Complete the drawing plan, overall dimensions, three-part relationship, and at least one verifiable part/detail drawing.

課堂路徑 / Class route

先讀完整範例 / Read the complete example

先辨認一份圖說如何安排整體、構造、零件與細部，不照抄未知尺寸。

作業參考推導過程

做圖面計畫 / Plan the sheet

先分配 A3 版面、視圖與比例；旋轉對稱零件採「足以說清楚的最少視圖」，不強迫每件都畫三視圖。

繪圖清單

建立整體骨架 / Draw the overall envelope

整體外觀與淨尺寸優先；細長物件可用折斷線，但尺寸仍標完整實長。

折斷線圖例

補結構與零件 / Add structure and parts

用爆炸圖交代三件之間的順序、方向與連接；零件圖與細部圖再標真正需要製作或驗證的尺寸。

尺寸標註圖例

交件前驗證 / Verify before submission

別人是否能指出尺寸屬於哪個部位、用相同方法重做，並分辨實測值與推定值？

比例不是為了把東西塞進紙張。

比例的目的，是讓線條、標註與關係保持可讀。圖面中的每個視圖都要標示比例；NTS 只能用在不作尺寸判讀的示意圖。

Scale is chosen for readability. Label the scale of every view; use NTS only for diagrams that are not used for dimensional measurement.
