W12 / 11/24

完成燈具圖組，列印驗收

這週做什麼

  1. 沿用自己的手繪證據、參數與 HTML，完成燈具整體三視圖、每個零件的三視圖、整體立體圖及爆炸圖。
  2. 逐張對照零件編號、外形、尺寸與組裝順序。有內部構造需要交代時，依已核對資料補剖面；待確認尺寸標在圖旁。
  3. 將圖組輸出為 A4 PDF，每張圖標明比例，今天交給老師並於課堂印出。先核對列印設定，再用直尺量輪廓及標註對應的位置。

這週繳交成果

  • 可重開的燈具 HTML。
  • A4 PDF 圖組：整體三視圖、各零件三視圖、立體圖、爆炸圖，附必要剖面。
  • 當堂紙本，以及至少一個水平尺寸與一個垂直尺寸的預期值、實測值和差值。
  • 一項尺寸差異的判讀與下一步修正。

驗收時指出：圖面標註多少？按比例紙上應有多長？實際量到多少？

W13 / 12/01

同一套工具，測三種外形

這週做什麼

  1. 先修正燈具列印驗收發現的比例、標註或跨圖矛盾。
  2. 使用共用題庫的圓盤、長方塊和 L 形件，在同一套工具切換參數與物件類型，生成對應圖面。
  3. 每題選一個參數，先預測改值效果，再核對不同視圖的輪廓與標註；選一題重新輸出 A4 並量測。

這週繳交成果

  • 包含前三種物件的 HTML 工作版及圖組。
  • 三題測試表：輸入參數、預期變化、實際結果與待修正項目。
  • 一題的 A4 PDF 與紙本量測紀錄。

換物件後，視圖方向、參數意義與比例仍能核對。

W14 / 12/08

補齊五題，建立 A4 排版初版

這週做什麼

  1. 加入帶通孔板件，以及空心或階梯孔件，核對孔位、壁厚、深度和剖切位置。
  2. 把已核對的視圖放入固定 A4 版型，安排圖名、圖號、比例、尺寸標註與版次。排版後重查一個水平與垂直尺寸。
  3. 選一個可用課堂材料製作的簡單零件或套合件，交別組先讀圖，記下不清楚的基準或尺寸。

這週繳交成果

  • 五種物件的圖組與驗收表，各項標示通過或待修正。
  • 第一版 A4 排版 PDF。
  • 供模型互驗的零件圖，包含比例、材料厚度及製作所需尺寸。
  • 外組讀圖回饋。

剖面尺寸有來源，別組能依圖指出要做的部件與基準。

W15 / 12/15

排版生成器與模型互驗

這週做什麼

  1. 依讀圖回饋修圖。排版生成器先做到選物件、選視圖、選比例與輸出 A4。
  2. 兩組交換已核對的零件圖。製作者先寫下讀到的尺寸與基準，再用紙板、泡棉或預裁材料完成一個局部模型。
  3. 作者先讓對方依圖操作，再一起比對圖面指定值、讀圖值及模型實測值，找出差異來源並修正。

這週繳交成果

  • 可操作的 A4 排版生成器。
  • 一件依外組圖面製作的局部模型。
  • 指定值、讀圖值、模型實測值的對照。
  • 有證據支持的一項圖面或工具修正，附前後版本。

能說明差異來自圖面、讀圖、材料或製作的哪個環節。

W16 / 12/22

期末展示與現場驗收

這週做什麼

  1. 展示工具、五種物件圖組與驗收結果，現場選一個參數改值，指出各視圖和標註的變化。
  2. 重新輸出一張圖，使用紙本或 DXF 抽查一個已知尺寸。
  3. 用模型互驗案例說明：別組發現什麼問題、你如何修正、修正後怎麼驗證。

這週繳交成果

  • 最終 HTML、必要附件與排版生成器。
  • 五種物件圖組與驗收紀錄。
  • 至少一張通過實尺驗收的 A4 圖與量測紀錄。
  • 模型互驗紀錄與修正前後版本。

讀者能從尺寸來源、圖面、輸出及量測紀錄追到你的修正依據。

五種物件要測什麼

使用尺寸已知的共用題庫。每題保留輸入參數、生成圖面、一次改值測試與待修正項目。燈具保留為原有開發案例。

物件主要驗收點
圓盤／底座外徑、厚度與跨圖連動
長方塊長寬高的投影對應與比例
L 形件不對稱輪廓、方向與缺口位置
帶通孔板件孔徑、孔位基準與板厚
空心／階梯孔件內外徑、壁厚、孔深與剖切位置

今天怎麼量 A4 紙本

PDF 內先設定圖面比例，列印選「實際大小／100%」。先量水平與垂直各一條紙上應為 100 mm 的校準線，再量物件尺寸。

確認外徑 Ø150 mm，採 1:2 時，紙上應量到 75 mm，圖面仍標 Ø150。記下紙上預期值、直尺實測值，以及差值（實測 − 預期）。

兩條校準線都偏差時，先查列印縮放；校準線正確而物件偏差時，查幾何與輸出比例；只有一個方向偏差時，查是否拉伸。實尺驗收以正投影與剖面上的指定位置量測。

模型互驗怎麼做

拿到外組圖面後，先寫下讀到的尺寸與基準，再製作並量測一個局部零件或套合件。比較圖面指定值、讀圖值與模型實測值，依結果說明一項修正。

Finish the lamp drawings and check a print

What to do

  1. Continue from your own sketches, evidence, parameters, and HTML. Complete three orthographic views of the whole lamp, three views of each part, an overall isometric view, and an exploded view.
  2. Cross-check part IDs, shapes, dimensions, and assembly order. Add a section where verified internal details need explanation. Mark dimensions awaiting verification beside the drawing.
  3. Export the drawing set as A4 PDF with a stated scale for each drawing. Submit it to the instructor today and print it in class. Check print settings, then measure the outlines at the dimensioned locations.

What to submit

  • A lamp HTML file that can be reopened.
  • An A4 PDF set with overall and individual-part orthographic views, an isometric view, an exploded view, and sections where needed.
  • The in-class print, with expected paper measurements, ruler readings, and differences for at least one horizontal and one vertical dimension.
  • An explanation of one discrepancy and the next correction to make.

Explain the dimension shown, the expected length on paper at the stated scale, and the actual ruler reading.

How to check the A4 print

Print at “Actual size / 100%.” Put the intended drawing scale in the PDF. Measure a horizontal and a vertical 100 mm calibration line first, then compare an object dimension with its expected paper length.

A confirmed Ø150 mm base at 1:2 should measure 75 mm on paper. The dimension label remains Ø150. Record the expected paper length, the ruler reading, and the difference (actual − expected).

If both calibration lines are off, check print scaling first. If they are correct but the part is off, check geometry and output scale. If only one axis is off, check for stretching. Measure orthographic and sectional views at the marked locations.

How the model exchange works

Before making the model, record the dimensions and datums you read from the other group’s drawing. Then make and measure a small part or fitting. Compare specified, interpreted, and measured values. Explain one correction using the results.
